### 2.2 📈 Swing Analysis (การเปลี่ยนแปลงระหว่าง 2 ปี)

ข้อมูลที่ต้องคำนวณเพิ่ม **ต่อเขต**:

| Feature | สูตร | ใช้ทำอะไร |
|---|---|---|
| `swing_pct` | vote_share_2569 - vote_share_2566 | ดูว่าพรรคไหนได้/เสียคะแนน |
| `winner_changed` | winner_2569 ≠ winner_2566 | เขตที่เปลี่ยนมือ |
| `alignment_shift` | alignment_2569 ≠ alignment_2566 | เขตที่เปลี่ยนแนวทาง |
| `turnout_change` | turnout_2569 - turnout_2566 | ผู้มาใช้สิทธิ์เปลี่ยนแปลง |
| `margin_of_victory` | vote_1st - vote_2nd | ชนะห่างแค่ไหน |
| `competitiveness` | 1 - (margin / total_votes) | เขตแข่งขันสูง |

## 3. Features สำหรับ AI Model

### 3.1 Features ที่คำนวณได้จากข้อมูลปัจจุบัน (ไม่ต้องหาเพิ่ม)

| # | Feature | คำนวณจาก | ประเภท |
|---|---|---|---|
| 1 | `region` | CSV | Categorical (7) |
| 2 | `province` | CSV | Categorical (77) |
| 3 | `eligible_voters` | CSV | Numeric |
| 4 | `turnout_rate` | total_votes / eligible_voters | Numeric |
| 5 | `invalid_rate` | invalid_votes / total_votes | Numeric |
| 6 | `num_candidates` | count per zone | Numeric |
| 7-16 | `vote_share_top10_2566` | vote_pct per party ปี 2566 | Numeric (10) |
| 17 | `progressive_share_2566` | sum % ฝ่ายก้าวหน้า | Numeric |
| 18 | `populist_share_2566` | sum % ฝ่ายประชานิยม | Numeric |
| 19 | `conservative_share_2566` | sum % ฝ่ายอนุรักษ์ | Numeric |
| 20 | `winner_alignment_2566` | alignment ของพรรคที่ชนะ | Categorical (4) |
| 21 | `margin_2566` | vote_1st - vote_2nd | Numeric |
| 22 | `competitiveness_2566` | ดูค่า margin | Numeric |
| 23 | `partylist_vs_constituency` | เทียบคะแนน 2 ระบบ | Numeric |

### 3.2 Features ที่ต้อง Hardcode เพิ่ม

| # | Feature | ข้อมูล | วิธี |
|---|---|---|---|
| 24 | `is_urban` | เขตเมือง/ชนบท | Hardcode (กทม.=urban, อื่นๆ=ดูจากชื่อเขต) |
